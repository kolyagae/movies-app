# Movie Search App

## Описание

Это приложение позволяет пользователям искать фильмы, фильтровать результаты поиска по жанрам, году выпуска, рейтингу и другим параметрам, а также просматривать детальную информацию о каждом фильме. Пользователи могут добавлять фильмы в список оценённых и управлять своими оценками.

Приложение было разработано как тестовое задание для участия в [**Startup Summer 2024**](https://paralect-global.notion.site/c3a7adc40e5d4e0d9d3d3e5462a576bc).

## Технологии

- **Frontend**: [Next.js](https://nextjs.org/), [Mantine UI](https://mantine.dev/)
- **Backend**: API маршруты Next.js для создания прокси-сервера
- **API**: [TMDB API](https://developer.themoviedb.org/docs/getting-started) для получения данных о фильмах
- **Хранилище**: LocalStorage для сохранения оценённых фильмов

## Страницы и функциональность

### 1. Главная страница
![ArrowFlicks](https://github.com/user-attachments/assets/a635f8ab-68e5-400e-8fba-e2f2c72acb8a)

#### Возможности:
- **Фильтрация по параметрам**: 
  - Жанры фильмов: выберите один или несколько жанров для фильтрации.
  - Год выпуска: укажите год выхода фильма.
  - Рейтинг: возможность установить диапазон оценок фильмов (от минимальной до максимальной).
  - Сортировка: пользователи могут сортировать результаты по рейтингу, дате выхода или популярности.
- **Пагинация**: Результаты отображаются с постраничной навигацией, где можно переключаться между страницами с помощью кнопок "Назад" и "Вперед".
- **Лоадер**: Во время загрузки данных отображается анимация загрузки (Loader).
- **Empty State**: Если фильмы не найдены по запросу, пользователю показывается сообщение об отсутствии результатов.

### 2. Страница фильма
![ArrowFlicks](https://github.com/user-attachments/assets/9c67c00f-6c0d-4f33-b6cb-4c43bab62879)



#### Возможности:
- **Детали фильма**: На странице отображается детальная информация о фильме, а так же список киностудий и трейлер (если доступен).
- **Оценка фильма**: Пользователь может оценить фильм, нажав на звезду. Оценка сохраняется в LocalStorage и фильм добавляется в список "Оценённые фильмы".

---

### 3. Страница оценённых фильмов

![ArrowFlicks](https://github.com/user-attachments/assets/e6ae7d59-19b9-42e8-8100-202dccbc3585)


#### Возможности:
- **Список оценённых фильмов**: Все фильмы, которые пользователь оценил, отображаются в виде карточек с постером, названием и оценкой.
- **Изменение оценки**: Пользователь может изменить свою оценку для любого фильма прямо на этой странице, нажав на звезду рядом с фильмом.
- **Удаление фильма**: Фильм можно удалить из списка оценённых, нажав повторно на звезду. Для подтверждения удаления выводится модальное окно.
- **Поиск по оценённым фильмам**: В строке поиска на странице можно искать фильмы по названию среди тех, которые были оценены.

## Примечания

- Приложение использует прокси-сервер для безопасного взаимодействия с TMDB API.
- Все данные о фильмах, которые вы оценили, хранятся в LocalStorage вашего браузера.
